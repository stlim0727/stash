## Stash v1.2.2

This release introduces preview image quick-open with sleek glassmorphism badges, consolidates view modes into a 2-tier design (Card vs List), expands title readability across all views, and includes Inbox search state restore fixes.

### ✨ Highlights

**Preview Image Quick-Open & Ribbon Badge (바로열기 & 리본 배지)**
- **Tap image to open**: Tapping the preview image in Card view or the thumbnail in List view now directly opens the external web page in your browser.
- **Glassmorphism Ribbon Overlay**: A subtle `domain.com ↗` glassmorphism badge is positioned on the top-right of preview images, providing clear visual affordance.
- **Expanded Title & URL Space**: Removed redundant `↗` buttons beside URL lines to maximize horizontal space for titles and URLs across all views.

**Streamlined 2-Tier View Modes (Card vs List)**
- **Consolidated Layouts**: Replaced 3-tier layout options with 2 distinct, highly optimized view modes:
  - **Card View (🖼️)**: Rich cover image cards for visual browsing.
  - **List View (☰)**: High-density compact row layout with small thumbnails for fast scannability and maximum title space.
- **Consistent Mental Model**: Tapping the image/thumbnail opens the web page; tapping the text opens Stash bookmark details.

### 🐛 Fixes
- **Inbox Search State Restore**: Fixed an issue where closing the Inbox search bar could unintentionally collapse a header row that was revealed before search was opened (`#569`).
