## Stash v0.1.8

A maintenance release on top of 0.1.7 — sync & reinstall fixes, clearer AI
progress, and better error reporting.

### 🐛 Fixes

- **Reinstalling restores your library.** Signing in now pulls your cloud data,
  so a fresh install or a new device repopulates instead of opening to an empty
  inbox. (#106)
- Sync no longer reports "synced" while a sync is still in flight. (#106)

### ✨ Improvements

- A **"working" indicator** while AI enrichment runs, so suggestions don't look
  stuck on slower model calls. (#103)
- Handled errors now **auto-report to Sentry** (release builds tag events as
  `production`), so issues surface instead of failing silently. (#107)
