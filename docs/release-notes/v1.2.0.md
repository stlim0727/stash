## Stash v1.2.0

Welcome to **Stash v1.2.0**! This milestone release introduces preview image quick-open with sleek glassmorphism badges, consolidates view modes into a streamlined 2-tier design (Card vs List), expands title readability across all views, and brings performance & security enhancements.

### ✨ Highlights

**1. Preview Image Quick-Open & Ribbon Badge (바로열기 & 리본 배지)**
- **Tap image to open**: Tapping the preview image in Card view (or the thumbnail in List view) now directly opens the external web page in your browser.
- **Glassmorphism Ribbon Overlay**: A subtle `domain.com ↗` glassmorphism badge is positioned on the top-right of preview images, providing a clear visual affordance that the image is a portal to the web.
- **Expanded Title & URL Space**: Removed redundant `↗` buttons next to URL lines, giving titles and URLs full horizontal width without truncation.

**2. Streamlined 2-Tier View Modes (Card vs List)**
- **Consolidated Layouts**: Replaced the 3-tier layout selector with 2 distinct, highly optimized view modes:
  - **Card View (🖼️)**: Rich cover image cards for visual browsing.
  - **List View (☰)**: High-density row layout with small thumbnails for fast scannability and maximum title space.
- **Consistent Mental Model**: In both Card and List views, **tapping the image opens the link**, and **tapping the text opens Stash detail & notes**.

**3. Bulk Action Polish & UI Refinements**
- **Bulk Action Icons**: Added clear visual icons to `Add All` and `Dismiss All` suggestion actions.
- **Smooth Graph View (Android)**: Eliminated pan/zoom snap-back flashing when releasing gestures in the Graph view.

**4. Privacy-Safe Telemetry & Performance Tracking**
- **Durable Share Measurement**: Added privacy-safe PostHog telemetry to track bookmark persistence latency and share intent performance without logging user content or URLs.
- **Sanitized Event Catalog**: Strict event allowlist ensuring zero user content leakage.

**5. Security & Infrastructure**
- Enforced Row-Level Security (RLS) across all auxiliary and backup tables.
- Updated automated release cleanup workflows for Firebase App Distribution.
