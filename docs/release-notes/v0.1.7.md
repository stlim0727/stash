## Stash v0.1.7

The first stable build since v0.1.5 — Stash gains real AI assistance, data
portability, OAuth sign-in, and a much sturdier capture-and-sync core.

### ✨ Highlights

**AI-assisted organizing**
- Content-aware enrichment powered by Google Gemini: auto-generated summaries,
  tag suggestions (with confidence), and a "move to the right collection" hint —
  all server-side, so no API key ships in the app, with a deterministic
  heuristic fallback when the model is unavailable. (#87, #101)
- One-tap tag suggestions pulled from `#hashtags` already in a captured caption
  (Instagram and the like) — Unicode/CJK-aware, so Korean tags work too. (#86)

**Your data is yours**
- Export your bookmarks from Settings: a universal **HTML** file any browser or
  bookmark app (Raindrop, Pocket, …) can import, plus a full-fidelity **JSON**
  backup. Works entirely offline. (#88)

**Capture & sharing**
- Configurable post-share behavior, defaulting to a quick modeless **toast** — a
  share no longer yanks you into the Inbox. (#89)
- Fewer duplicate saves: share-race handling, canonical `url_hash`, and cloud
  de-duplication; YouTube/`share.google` tracking params are stripped during URL
  canonicalization. (#95, #98, #97)

**Sync reliability**
- Self-heals bookmarks stranded in "sync pending" with no queue entry, and
  reclaims entries stuck mid-"syncing". (#92, #52)
- Tagging is now local-first — optimistic, queued, and fully offline. (#72)
- Switching accounts no longer wipes the local cache. (#59)

**Accounts**
- Sign in with **Apple** or **Google** (PKCE OAuth); discoverable login from the
  Inbox, with build provenance shown in Settings. (#49, #51)

**Refined UI**
- Redesigned bookmark **Detail** screen: token-style tags, collection picker,
  in-place editing; overlong captions collapse behind "Show more". (#68, #85)
- Redesigned **Settings**: compact grouped layout, account avatar, developer
  mode for diagnostics. (#74)
- **Inbox**: collapsing header, long-press action menu, and a card/list view
  toggle. (#81, #53)

**Distribution**
- Installable Android APKs straight from CI — every build is published as a
  GitHub Release with a scan-to-install QR code, no EAS account required.
  (#82, #64)
